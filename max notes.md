# Max Notes

UI and product improvements to discuss and implement.

## Grading

- [ ] Make the icons for the 1–4 scoring options larger and easier to scan/click.
- [ ] Make the toggle between **Resume** and **Free response** much more obvious. The active mode should be unmistakable.
- [ ] Improve the Resume Screener progress display. A percentage score by itself is not very useful.
- [ ] Add a progress bar showing how many reviews have been completed out of the expected or assigned total.
- [ ] Keep grading progress/coverage visually separate from the candidate's actual score so the two cannot be confused.

## Admin home

- [ ] Move the recruiting-cycle timeline to the top of the Admin home page.
- [ ] Rework the **Attention** area around **Reviews left** as the primary actionable metric.
- [ ] Add grader-status information below Reviews left, including who has started and who is behind on reviews.
- [ ] Reconsider or remove the green **9 categories** indicator; its meaning and value are currently unclear.

## Open decisions

- [ ] Define the denominator for the grading progress bar: assigned reviews, individual review goal, or all resumes in the active cycle.
- [ ] Define when a grader counts as **behind** (for example, relative to a deadline, expected pace, or team average).
- [ ] Decide what should replace the **9 categories** indicator, if anything.
